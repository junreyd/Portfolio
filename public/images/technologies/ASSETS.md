# Technology brand assets

Locally served brand marks identify technologies in Junrey's portfolio. The marks retain their source colors and aspect ratios. Their respective owners retain their trademarks. No runtime icon CDN is required.

- Microsoft 365: [2022 Microsoft 365 mark](https://commons.wikimedia.org/wiki/File:Microsoft_365_(2022).svg).
- SharePoint: Microsoft's Fluent Office brand CDN, `https://static2.sharepointonline.com/files/fabric/assets/brand-icons/product/svg/sharepoint_48x1.svg`.
- Power Platform, Power Apps, Power Automate, Dataverse, AI Builder, and Copilot Studio: [official Microsoft Power Platform icon pack](https://learn.microsoft.com/en-us/power-platform/guidance/icons), December 2025 collection. Copilot Studio is the current product identity for the former Power Virtual Agents.
- Azure Functions and Logic Apps: [official Azure icon pack](https://learn.microsoft.com/en-us/azure/architecture/icons/), V24.
- Business Central: [official Dynamics 365 icon pack](https://learn.microsoft.com/en-us/dynamics365/get-started/icons).
- Power BI: [Microsoft's Power BI Icons repository](https://github.com/microsoft/PowerBI-Icons/blob/main/SVG/Power-BI.svg).
- Microsoft Graph: [Microsoft Graph mark in Ben Coleman's icon collection](https://github.com/benc-uk/icon-collection/blob/master/other/graph-api.svg).
- Liquid: [Shopify's official Liquid documentation icon](https://shopify.github.io/liquid/images/icons/water-drop-64x.png).
- Frappe HR: [official Frappe HR favicon](https://github.com/frappe/hrms/blob/develop/frontend/public/favicon.png).
- PnP PowerShell: [official PnP PowerShell package icon](https://github.com/pnp/powershell/blob/dev/nugeticon.png).
- Power Fx: [official Microsoft Power Fx package icon](https://github.com/microsoft/Power-Fx/blob/main/src/powerfx_icon.png).
- Shopify, Xero, and ERPNext: [Simple Icons](https://simpleicons.org/), in their brand colors. Simple Icons is CC0; brand trademarks remain with their owners.
- JavaScript, TypeScript, React, HTML5, CSS3, Sass, Node.js, C#, .NET, PowerShell, Vite, Tailwind CSS, Vue, Angular, Salesforce, PHP, Laravel, and CodeIgniter: [Devicon](https://github.com/devicons/devicon/tree/master/icons), MIT-licensed collection of the respective brand marks.

Each technology has one name and one mark. REST is an architectural style and has no single official product logo; its entry uses a neutral code-braces icon from Lucide. LWC is represented by the Salesforce mark and SPFx by the SharePoint mark. These are technology labels, not affiliation or certification claims.

Additional skills-orbit assets:

- Git: [official Git logo](https://git-scm.com/downloads/logos), `Git-Icon-1788C.svg`.
- GitHub: black and white Invertocat SVGs from the [official GitHub logo pack](https://brand.github.com/GitHub_Logos.zip), retained without editing.
- Bootstrap: [official Bootstrap brand mark](https://getbootstrap.com/docs/5.3/assets/brand/bootstrap-logo.svg).
- Outlook add-ins: Microsoft Fluent Office brand CDN, `https://static2.sharepointonline.com/files/fabric/assets/brand-icons/product/svg/outlook_48x1.svg`.
- SharePoint Server uses the SharePoint product mark. Existing SPFx, Salesforce LWC, and REST representations follow the same conventions as the technology strip.
