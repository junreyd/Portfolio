# Project screenshots

The PNG screenshots were supplied by Junrey Ducay for this portfolio. Originals are preserved; responsive cropping and framing happen in the card CSS. The detail gallery displays full screenshots and offers an enlarged view.

`src/data/projects.ts` groups these into 13 distinct solutions. Multiple captures of the Pacer task app, earlier Outlook archiving UI, repeated notification styling, and overlapping ADC navigation views are omitted from the showcased selection. Related screens that demonstrate different features remain together in their project gallery.

The `abiso/` folder contains six original Abiso screenshots copied from the supplied files in `public/images/profile/`. Descriptive filenames identify the desktop dashboard, admin overview, member management, system logs, and two mobile layouts. The overlapping browser-framed log capture is omitted. The card pairs the desktop screenshot with a mobile inset using CSS; the gallery shows each original in full. No text, figures, or interface details in the screenshots have been redrawn.

The four original SVG concept images are retained as unused legacy assets. They are not displayed in the Projects section.

The `jumex/` folder contains eight original JUMEX screenshots with descriptive filenames for checkout, inventory, customer discounts, employee records, attendance, payroll, product history, and profit reporting. The two employee list captures have identical SHA-256 hashes; only one appears in the gallery. CSS frames the checkout card around the main working area; the gallery preserves the full screenshots and their original text and figures.
